# TarkovKdDown

这个项目提供了一个基于Python的自动化工具，用于在《逃离塔科夫》(Escape from Tarkov)游戏中自动执行送死掉KD的流程。通过图像识别和键鼠模拟，实现全自动化操作，无需人工干预。

## 功能特点

- **全自动流程**：从选择PMC到死亡后返回主菜单的完整自动化
- **图像识别**：使用OpenCV进行屏幕图像识别，精确定位界面元素
- **键鼠控制**：Windows驱动层级的键盘和鼠标模拟
- **状态机设计**：稳定可靠的工作流程控制
- **详细日志**：记录每个操作步骤，便于调试和监控
- **可配置性**：易于调整超时时间、匹配阈值等参数
- **进程监控**：自动检测游戏进程是否存在，并在异常时尝试重启游戏

## 系统要求

- Windows操作系统
- Python 3.7+
- **游戏设置**：
  - **分辨率**: 1280x800（默认，其他分辨率需替换对应截图）
  - **显示模式**: 窗口化（全屏可能导致识别问题）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 基本使用

1. 确保游戏设置为窗口化模式，分辨率为1280x800
2. 首次进入工厂需要手动吃一个蛋黄酱，并找AI打出出血效果
3. 运行启动脚本：`python run.py`
4. 程序启动后，会提示您在3秒内切换到游戏窗口
5. 之后程序会自动执行完整的送死流程

### 自定义流程

如需自定义流程，可以修改`src/main.py`中的`WorkflowState`枚举和`WorkflowStateMachine.execute()`方法。

### 替换截图

如果您使用不同的分辨率或界面，需要替换模板图片：

1. 使用截图工具截取需要识别的界面元素
2. 将截图保存到`data/images`文件夹
3. 使用以下代码添加图片：

```python
from src.image.image_manager import add_image

# 添加图片
add_image("path/to/your/screenshot.png", "image_name")
```

默认需要的图片包括：

- `escape.png`: 主界面的"ESCAPE"按钮
- `pmc.png`/`pmc_select.png`: PMC选择界面
- `nextstep.png`: "下一步"按钮
- `factory.png`/`factory_select.png`: 工厂地图选择
- `ready.png`: 准备按钮
- `in_game.png`: 游戏中界面标识
- `main_menu.png`: 返回主菜单按钮
- `yes.png`: 确认对话框中的"是"按钮

## 工作原理

程序使用状态机模式实现自动化流程：

1. **初始化系统**：等待用户切换到游戏窗口
2. **等待主界面加载**：识别主界面并点击进入
3. **选择PMC角色**：选择PMC角色
4. **进行下一步操作**：点击下一步按钮
5. **选择工厂地图**：选择Factory(工厂)地图
6. **准备部署角色**：点击准备按钮进入游戏
7. **等待游戏开始**：等待游戏加载完成
8. **等待角色死亡**：等待角色死亡
9. **返回主菜单**：死亡后返回主菜单
10. **确认对话框选项**：确认返回主菜单
11. **循环**：重复以上步骤

## 注意事项

- 本工具仅用于学习和研究目的，请遵守游戏规则和条款
- 长时间使用自动化工具可能会被游戏检测，请谨慎使用
- 不同的游戏版本可能需要更新模板图片
- 如遇识别问题，可尝试调整`wait_for_image`函数中的`threshold`参数

## 故障排除

- **无法识别图像**：检查游戏分辨率和窗口模式，更新模板图片
- **点击位置不准确**：确保游戏窗口位置固定，或重新截取模板图片
- **程序卡在某个状态**：检查日志文件，可能是超时设置不足或模板图片不匹配
- **游戏进程不存在**：程序会自动检测并尝试重启游戏，如果失败，请手动启动游戏
